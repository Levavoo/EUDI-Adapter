# Use Cases — EUDI Wallet Relying Party Integration Bus

## 1. Overview

This document describes business use cases for the EUDI Wallet Relying Party Integration Bus.

The purpose is to translate real organizational identity-check needs into structured, privacy-preserving verification request scenarios.

The use cases should stay business-focused first. Technical implementation details, schemas, endpoints, and storage decisions should be derived from these use cases later.
