## Purpose

This notebook stores EUDI Wallet-specific research for the relying-party-side prototype.

It covers ARF, eIDAS, ecosystem roles, PID, EAA, QEAA, selective disclosure, privacy warnings, trust context, official sources, and project relevance.

---

## Project perspective

The project focuses on the organization / relying party / verifier side.

The prototype helps an organization translate a business identity-check requirement into a privacy-aware wallet verification request, process a simulated wallet response, validate the result, generate privacy warnings, and record audit-log events.

The project does not build a real EUDI Wallet.
